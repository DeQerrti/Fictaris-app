# Fictaris

Инструмент для писателей и мастеров миров — альтернатива Obsidian, специализированная под worldbuilding и художественное письмо: персонажи, локации, фракции, связи, таймлайн, интерактивная карта, канбан-доска и текстовый редактор в одном месте.

Настольное приложение (Electron): данные лежат папкой на диске, никакой облачной базы. Архитектура — по образцу [TasteID](https://github.com/DeQerrti/tasteid-app): локальный HTTP-сервер отдаёт ванильный JS/HTML-фронтенд и API, `Vault` пишет JSON атомарно (через временный файл + rename) и держит `.history` прошлых версий на каждый файл.

## Статус

Реализовано:
- **Рукопись** — список глав, статус (Черновик/На редактуре/Готово), счётчик слов, заметки автора, автосохранение с debounce и индикатором «Сохранение…/Сохранено», экспорт всей рукописи в `.md` (главы через `---`, заметки автора не входят)
- **Персонажи** — карточки с цветовой меткой, drawer-редактор с полями внешности/характера/мотивации/цели/слабостей/предыстории/тегов, реверс-связи в карточке (связи, события таймлайна, фракции, карточки доски, метки на карте — где ещё упомянут)
- **Локации** — карточки с типом (город/подземелье/опасность/сокровище/другое, у каждого своя иконка и цвет), описание/заметки/теги, реверс-связи (события таймлайна, фракции со штабом здесь, метки на карте)
- **Связи** — SVG-граф персонажей (узлы по кругу, линии окрашены по шкале -100..+100: красный — вражда, зелёный — союз), список связей под графом со слайдером и заметкой
- **Таймлайн** — интерактивная дата (число в свободном тексте задаёт позицию на шкале), drag-and-drop через fractional order (порядок = среднее соседей, не полная перенумерация — сосуществует с автопозиционированием по дате без конфликтов), привязка события к персонажам и локациям, фильтр по персонажам с счётчиком «N из M событий»
- **Доска** (канбан) — колонки и карточки с drag-and-drop (между колонками и внутри), переименование/удаление колонок (инлайн-подтверждение вместо `confirm()`), привязка карточки к персонажу
- **Данные** — экспорт всего проекта в один `.json` (с версией схемы и датой), импорт с инлайн-подтверждением полной замены, «Заполнить примером» — связный тестовый сюжет во всех модулях сразу
- **Фракции** — тип (иконка+цвет: орден/монархия/культ/военная организация/синдикат/другое), глава и штаб-квартира (выбор из персонажей/локаций), состав (мультиселект-чипы), описание/идеология
- **Карта** — загрузка изображения со сжатием через `<canvas>` (масштаб + JPEG quality) перед отправкой на диск, картинки — отдельные файлы в `maps/`, а не base64 в JSON; метка может быть привязана к персонажу и/или локации (иконка и цвет метки берутся из типа локации, если она указана); вложенные под-карты через метки-порталы с хлебными крошками и рекурсивным удалением
- **`@упоминания`** — автолинк и автодополнение в тексте главы и в описании события таймлайна; исправлен баг с кириллицей (`\b` в JS-регулярках не считает кириллицу словообразующей — заменено на negative lookahead, длинные имена матчатся раньше коротких); переключатель Правка/Просмотр в редакторе главы, клик по упоминанию в режиме просмотра открывает карточку персонажа
- **Корзина** — персонажи, локации, связи, фракции, события таймлайна и карточки доски при удалении уходят в корзину, а не пропадают; восстановление возвращает элемент в его модуль (карточка доски — в отдельную колонку «Восстановлено», раз исходной колонки может уже не быть), «Удалить навсегда» с инлайн-подтверждением, счётчик в сайдбаре — то самое, что в прошлой попытке было начато (`onTrash` в модулях), но не доведено до уровня приложения
- **Граф проекта** — общий SVG-граф персонажей, локаций и фракций (цвет и иконка — по типу), рёбра строятся автоматически из связей, состава фракций и совместных упоминаний в событиях таймлайна; при наведении на узел его связи подсвечиваются, остальное гаснет
- **Проверка согласованности** — четыре проверки по всем модулям сразу: битые ссылки (связь/фракция/событие/карточка/метка на карте ссылаются на несуществующую сущность), «забытые» персонажи и локации (нигде не упомянуты), возможные дубли на таймлайне (совпадают название и дата), главы со статусом «Готово» с пустым текстом

Сознательно отложено (см. `scriptorium-project-brief.md` — исходный бриф с прошлой попытки под старым названием "Скрипторий", там весь список задуманного функционала и технических решений):
- Несколько независимых карт верхнего уровня (только одно дерево от корневой карты)
- Реверс-связи во фракциях (у персонажей и локаций уже есть, у фракций пока нет — им особо нечего показывать сверх того, что видно и так)
- Фильтр таймлайна по локациям (сделан только по персонажам — как и в прошлой попытке)
- Цветная метка карточки доски отдельно от персонажа, привязка карточки к событию/главе, шаблоны структуры (Три акта / Путь героя)
- Hover-превью карточки персонажа при наведении на упоминание (сейчас только клик), инлайн-стикеры, снимки версий, фокус-режим, drag-and-drop сортировка глав, родословное древо
- Экспорт в `.docx`, многопроектность
- История версий в UI (файлы `.history` в `Vault` уже пишутся на диск при каждом сохранении, интерфейса для просмотра/отката пока нет)

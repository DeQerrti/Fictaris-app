# Fictaris

**Стол писателя и мастера миров.** Рукопись, персонажи, локации, фракции, таймлайн, карты и холсты – в одном приложении. Проект лежит обычной папкой на вашем диске, без облака и без регистрации.

[English version](README.en.md) · [Скачать](https://github.com/DeQerrti/Fictaris-app/releases/latest) · [Что нового](CHANGELOG.md) · [Сообщить о проблеме](https://github.com/DeQerrti/Fictaris-app/issues)

## Что умеет

- **Рукопись.** Несколько книг в одном мире, части и папки, статусы глав, цель по словам на книгу и на день. В главе – синопсис, кто и где в ней, заметки, стикеры в тексте, снимки версий. Режим «Обзор» показывает книгу карточками по частям. Экспорт в `.md`, `.docx`, PDF и EPUB.
- **Персонажи.** «Состав» по значимости, родам или фракциям и «Досье» с анкетой, семьёй, отношениями и тем, где персонаж встречается в сюжете. Поля анкеты настраиваются.
- **Родословная** с браками, помолвками, разводами, приёмными и предполагаемыми детьми. Режим «Фокус» показывает, кто кем кому приходится.
- **Отношения** – карта связей персонажей с силой от вражды до близости.
- **Локации и фракции.** Вложенные места с мини-картой, фракции с главой, составом, штабом и отношениями между собой.
- **Таймлайн.** «Летопись», «Шкала» по персонажам и «Календарь» своего мира: свои месяцы, недели, праздники, дни рождения.
- **Карты.** Загрузите картинку или нарисуйте карту прямо в приложении: суша, вода, реки, дороги, горы, города, границы фракций. Метки, вложенные карты.
- **Холсты** – доска в духе Excalidraw: карточки (в том числе персонажи, места и главы из мира), стрелки, рамки, фигуры, рисование от руки.
- **Доска** – канбан для сцен, идей и правок с чек-листами.
- **Кто что знает** – с какой главы персонажу известен факт.
- **Проверка согласованности**, глобальный поиск (`/`), корзина, история версий каждого файла, генератор имён.
- **Экспорт мира** сайтом или PDF; резервная копия всего проекта в один файл.
- **Синхронизация** между устройствами через ваш приватный репозиторий на GitHub (по желанию).
- Русский и английский интерфейс, светлая и тёмная темы.

Чтобы посмотреть всё сразу, откройте **Настройки → Этот мир → Данные → «Заполнить примером»**: появится связный тестовый мир. Убрать его можно там же.

## Установка

Скачайте файл для своей системы со [страницы последней версии](https://github.com/DeQerrti/Fictaris-app/releases/latest).

Приложение пока **не подписано** сертификатом разработчика, поэтому при первом запуске система предупредит, что издатель неизвестен. Это ожидаемо.

### Windows 10 и 11
Файл `Fictaris-Setup-X.Y.Z.exe`.
1. Запустите установщик. Если появится окно «Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. Если включён Smart App Control (Windows 11), он может заблокировать неподписанное приложение без кнопки «Выполнить». Тогда установить Fictaris можно, только выключив Smart App Control в «Безопасность Windows → Управление приложениями и браузером». Учтите: включить его обратно Windows позволяет только после переустановки системы.

Обновления на Windows скачиваются сами; приложение предложит перезапуститься.

### macOS 12 и новее
Файл `Fictaris-Setup-X.Y.Z-arm64.dmg` для Apple Silicon (M1 и новее) или `…-x64.dmg` для Mac с Intel.
1. Откройте `.dmg` и перетащите Fictaris в «Программы».
2. При первом запуске macOS скажет, что приложение нельзя открыть или что оно «повреждено». Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** напротив Fictaris.
3. Если кнопки нет, выполните в «Терминале» и запустите снова:
   ```bash
   xattr -cr /Applications/Fictaris.app
   ```

На Mac приложение сообщает о новой версии, но устанавливать её нужно вручную тем же способом.

### Linux
Файл `Fictaris-Setup-X.Y.Z.AppImage` (x86-64).
```bash
chmod +x Fictaris-Setup-*.AppImage
./Fictaris-Setup-*.AppImage
```
На Ubuntu 22.04 и новее может понадобиться `sudo apt install libfuse2`. Если на Ubuntu 24.04 приложение не стартует с ошибкой песочницы, запустите его с ключом `--no-sandbox`.

### Android 7 и новее
Файл `Fictaris-X.Y.Z.apk`. Откройте его на телефоне и разрешите установку из этого источника, когда Android спросит.

## Где лежат данные

Проект – это папка, которую вы выбрали при первом запуске (по умолчанию `Документы/Fictaris`). Внутри – JSON-файл на каждый раздел, картинки в `maps/` и история версий в `.history/`. Папку можно копировать, класть в облачный диск или в git.

- **История версий.** Прошлые версии каждого файла хранятся в `.history/`: всё за последний час, по одной на час за сутки, по одной на день за месяц. Откатиться можно в **Настройки → Этот мир → Данные → История версий**.
- **Корзина.** Удалённые персонажи, места, главы и прочее сначала попадают в корзину.
- **Файл `CLAUDE.md`** в папке проекта – описание формата файлов для ИИ-ассистентов, которые умеют работать с папками (например, Claude Code). Приложению он не нужен; его можно удалить – Fictaris создаст его снова, – или убрать первую строку, и тогда он станет вашим и перезаписываться не будет.
- **На телефоне** проект хранится внутри приложения. Если удалить приложение, проект удалится вместе с ним, поэтому настройте синхронизацию или делайте резервную копию (**Данные → Экспорт проекта**).

## Приватность

Fictaris не собирает никаких данных и не отправляет ваши тексты никуда, кроме мест, которые вы настроили сами. Сетевые обращения:

- **Проверка обновлений** – запрос к GitHub о последней версии при запуске. На Windows и Linux новая версия скачивается сама. Выключается в **Настройки → Приложение → Обновления**.
- **Синхронизация** (только если включите) – обмен файлами проекта с вашим репозиторием на GitHub. Токен доступа хранится только на этом устройстве и не попадает ни в проект, ни в экспорт.

## Лицензия

Всё, что вы пишете и создаёте в Fictaris, – ваше: используйте, публикуйте и продавайте как угодно. Само приложение можно бесплатно скачивать и использовать для любых проектов, в том числе коммерческих. Исходный код закрыт для копирования и изменения. Подробности – в [LICENSE](LICENSE).

## Для разработчиков

Electron и Capacitor (Android), ванильный JavaScript на ES-модулях без фреймворков. Формат файлов проекта описан в [`electron/vault-guide.md`](electron/vault-guide.md). Установщики собираются в GitHub Actions (`.github/workflows/build.yml`).

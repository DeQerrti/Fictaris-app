# Fictaris

Инструмент для писателей и мастеров миров — альтернатива Obsidian, специализированная под worldbuilding и художественное письмо: персонажи, локации, фракции, связи, таймлайн, интерактивная карта, канбан-доска и текстовый редактор в одном месте.

Настольное приложение (Electron): данные лежат папкой на диске, никакой облачной базы. Архитектура — по образцу [TasteID](https://github.com/DeQerrti/tasteid-app): локальный HTTP-сервер отдаёт ванильный JS/HTML-фронтенд и API, `Vault` пишет JSON атомарно (через временный файл + rename) и держит `.history` прошлых версий на каждый файл.

## Статус

Реализовано:
- **Рукопись** — список глав, статус (Черновик/На редактуре/Готово), счётчик слов, заметки автора, автосохранение с debounce и индикатором «Сохранение…/Сохранено»
- **Персонажи** — карточки с цветовой меткой, drawer-редактор с полями внешности/характера/мотивации/цели/слабостей/предыстории/тегов
- **Локации** — карточки с типом (город/подземелье/опасность/сокровище/другое, у каждого своя иконка и цвет), описание/заметки/теги
- **Связи** — SVG-граф персонажей (узлы по кругу, линии окрашены по шкале -100..+100: красный — вражда, зелёный — союз), список связей под графом со слайдером и заметкой
- **Таймлайн** — интерактивная дата (число в свободном тексте задаёт позицию на шкале), drag-and-drop через fractional order (порядок = среднее соседей, не полная перенумерация — сосуществует с автопозиционированием по дате без конфликтов), привязка события к персонажам и локациям, фильтр по персонажам с счётчиком «N из M событий»
- **Доска** (канбан) — колонки и карточки с drag-and-drop (между колонками и внутри), переименование/удаление колонок (инлайн-подтверждение вместо `confirm()`), привязка карточки к персонажу
- **Данные** — экспорт всего проекта в один `.json` (с версией схемы и датой), импорт с инлайн-подтверждением полной замены, «Заполнить примером» — связный тестовый сюжет во всех модулях сразу

Сознательно отложено (см. `scriptorium-project-brief.md` — исходный бриф с прошлой попытки под старым названием "Скрипторий", там весь список задуманного функционала и технических решений):
- Фракции, карта, граф всего проекта, проверка согласованности
- Реверс-связи в карточках (локация/персонаж не показывают события, которые на них ссылаются)
- Фильтр таймлайна по локациям (сделан только по персонажам — как и в прошлой попытке)
- Цветная метка карточки доски отдельно от персонажа, привязка карточки к событию/главе, шаблоны структуры (Три акта / Путь героя)
- `@упоминания` персонажей в тексте, drag-and-drop сортировка глав, родословное древо
- Экспорт в `.md`/`.docx`, многопроектность
- Корзина, история версий в UI (файлы `.history` уже пишутся на диск, интерфейса для них пока нет)

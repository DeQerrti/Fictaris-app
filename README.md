# Fictaris

Инструмент для писателей и мастеров миров — альтернатива Obsidian, специализированная под worldbuilding и художественное письмо: персонажи, локации, фракции, связи, таймлайн, интерактивная карта, канбан-доска и текстовый редактор в одном месте.

Настольное приложение (Electron): данные лежат папкой на диске, никакой облачной базы. Архитектура — по образцу [TasteID](https://github.com/DeQerrti/tasteid-app): локальный HTTP-сервер отдаёт ванильный JS/HTML-фронтенд и API, `Vault` пишет JSON атомарно (через временный файл + rename) и держит `.history` прошлых версий на каждый файл.

## Статус

Реализовано:
- **Рукопись** — список глав с drag-and-drop сортировкой, статус (Черновик/На редактуре/Готово), счётчик слов, заметки автора, автосохранение с debounce и индикатором «Сохранение…/Сохранено»; переключатель Правка/Просмотр, фокус-режим (⛶, прячет сайдбар и список глав, выход по Esc); инлайн-стикеры `[[note:id]]` с попапом по клику; снимки версий главы (до 20, с восстановлением); экспорт всей рукописи в `.md` и в `.docx` (собственный минимальный ZIP/OOXML-писатель без внешних библиотек — заметки автора не входят ни туда, ни туда)
- **Персонажи** — карточки с цветовой меткой, drawer-редактор с полями внешности/характера/мотивации/цели/слабостей/предыстории/тегов, реверс-связи в карточке (связи, события таймлайна, фракции, карточки доски, метки на карте — где ещё упомянут)
- **Локации** — карточки с типом (город/подземелье/опасность/сокровище/другое, у каждого своя иконка и цвет), описание/заметки/теги, реверс-связи (события таймлайна, фракции со штабом здесь, метки на карте)
- **Связи** — SVG-граф персонажей (узлы по кругу, линии окрашены по шкале -100..+100: красный — вражда, зелёный — союз), список связей под графом со слайдером и заметкой
- **Фракции** — тип (иконка+цвет: орден/монархия/культ/военная организация/синдикат/другое), глава и штаб-квартира (выбор из персонажей/локаций), состав (мультиселект-чипы), описание/идеология
- **Таймлайн** — интерактивная дата (число в свободном тексте задаёт позицию на шкале), drag-and-drop через fractional order (порядок = среднее соседей, сосуществует с автопозиционированием по дате), привязка события к персонажам и локациям, независимые фильтры по персонажам и по локациям (сужают список одновременно) со счётчиком «N из M событий»
- **Доска** (канбан) — колонки и карточки с drag-and-drop (между колонками и внутри), переименование/удаление колонок (инлайн-подтверждение вместо `confirm()`), привязка карточки к персонажу, цветная метка карточки отдельно от персонажа, шаблоны структуры (Три акта / Путь героя)
- **Карта** — несколько независимых карт верхнего уровня (экран-витрина, «+ Новая карта»), у каждой — своё дерево вложенных под-карт через метки-порталы с хлебными крошками и рекурсивным удалением; загрузка изображения со сжатием через `<canvas>` перед отправкой на диск, картинки — отдельные файлы в `maps/`, а не base64 в JSON; метка привязывается к персонажу и/или локации (иконка и цвет — из типа локации, если она указана)
- **`@упоминания`** — автолинк и автодополнение в тексте главы и в описании события таймлайна; исправлен баг с кириллицей (`\b` в JS-регулярках не считает кириллицу словообразующей — заменено на negative lookahead, длинные имена матчатся раньше коротких); hover-превью карточки персонажа при наведении, клик открывает саму карточку
- **Корзина** — персонажи, локации, связи, фракции, события таймлайна и карточки доски при удалении уходят в корзину, а не пропадают; восстановление возвращает элемент в его модуль (карточка доски — в отдельную колонку «Восстановлено»), «Удалить навсегда» с инлайн-подтверждением, счётчик в сайдбаре
- **Граф проекта** — общий SVG-граф персонажей, локаций и фракций (цвет и иконка — по типу), рёбра автоматически из связей, состава фракций и совместных упоминаний в таймлайне; hover подсвечивает связи узла
- **Проверка согласованности** — битые ссылки, «забытые» персонажи и локации, возможные дубли на таймлайне, главы «Готово» с пустым текстом
- **Данные** — экспорт всего проекта в один `.json`, импорт с инлайн-подтверждением, «Заполнить примером»; история версий (Vault пишет `.history` на каждое сохранение — здесь витрина для просмотра и отката к любой прошлой версии любого модуля)
- **Многопроектность** — переключатель проекта в сайдбаре: несколько независимых хранилищ (папок на диске), быстрое переключение, добавление нового или существующего, переименование, удаление из списка (файлы на диске не трогает)

Сознательно отложено (см. `scriptorium-project-brief.md` — исходный бриф с прошлой попытки под старым названием "Скрипторий"):
- Реверс-связи во фракциях (персонажам и локациям есть что показывать — фракциям пока особо нечего сверх того, что видно в самой карточке)
- Привязка карточки доски к конкретному событию таймлайна или главе рукописи
- Родословное древо и категория связи «Семья»

## Разработка

```bash
npm install
npm start
```

```bash
npm run build        # текущая платформа
npm run build:win
npm run build:mac
npm run build:linux
```
